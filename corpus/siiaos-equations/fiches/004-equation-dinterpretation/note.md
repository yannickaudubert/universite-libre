# 4. Équation d’interprétation

![Fiche visuelle](./fiche.png)

## Finalité

Donner du sens selon les perspectives.

## Formule / structure

$$
I = \sum_{j=1}^{m} \omega_j \cdot R_j
$$

## Variables

- `I` : Interprétation
- `R_j` : Lecture / interprétation j
- `ω_j` : Poids contextuel
- `m` : Nombre de lectures

## Interprétation

Le sens n’est pas dans la représentation : il est construit par le lecteur selon son point de vue. Le sens est situé, pas neutre.

## Cas d’usage

- Comparer des points de vue métier
- Faire émerger des angles morts
- Traduire pour plusieurs publics
- Éviter le faux consensus

## Exemple concret

Une même représentation est lue différemment par un technicien, un manager et un décideur territorial.

## À retenir

> Le sens n’est jamais neutre, il est situé.
