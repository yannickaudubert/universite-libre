# Gouvernance des connaissances

Ce dépôt distingue le fait de **conserver une idée** du fait de **la publier comme connaissance établie**.

## Statuts minimaux

- `trace` : élément brut conservé ;
- `hypothese` : proposition à tester ;
- `conceptuel` : modèle utile pour penser ou agir, sans prétention de loi scientifique ;
- `source` : élément externe attribué et daté ;
- `verifie` : vérification documentée ;
- `valide` : validation selon un protocole explicite ;
- `publie` : contenu revu et volontairement exposé ;
- `commun` : ressource publiée avec licence et gouvernance explicites.

## Règle de publication

La publication publique n'est jamais déduite automatiquement de la présence d'un fichier dans le wiki personnel.
