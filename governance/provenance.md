# Provenance

Chaque ressource importante doit pouvoir indiquer :

- auteur ou contributeur ;
- date de création ;
- source originale ;
- transformations successives ;
- version ;
- statut de maturité ;
- niveau de preuve ;
- licence ou droits connus ;
- liens avec les objets dérivés.

Pour les productions humain-IA, conserver autant que possible la chaîne permettant de comprendre ce qui vient de l'humain, de la source, du modèle et de la révision humaine.
